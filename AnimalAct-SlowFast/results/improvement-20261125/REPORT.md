## 不确定性

按视频成组配对重采样 300 次，mAP 差的 95% 分位区间为 [-0.45, +1.23] 个百分点；Macro-F1 为 [-3.28, +0.74] 个百分点。
该区间描述固定模型在当前测试视频上的抽样差异，不代表不同随机种子的训练波动。区间跨过 0 时，不能称为稳定或显著提升。

## 文件与复现

- PLAN.md / plan.json：实验设置。
- context32.log / motion32.log / asymmetric32.log：完整训练记录。
- selection-frozen.json：测试评估前冻结的模型、输入、权重和阈值。
- summary.json：最终数值与配对重采样区间（若有通过验证选择的新方案）。
- 项目根目录 improve.py：运行入口；train_strong.py 的新选项均可独立调用。

方法参考：Ridnik et al., Asymmetric Loss for Multi-Label Classification, ICCV 2021，https://openaccess.thecvf.com/content/ICCV2021/html/Ridnik_Asymmetric_Loss_for_Multi-Label_Classification_ICCV_2021_paper.html 。本项目按标签判断数取均值，公开实现采用求和，归一化差异已注明。

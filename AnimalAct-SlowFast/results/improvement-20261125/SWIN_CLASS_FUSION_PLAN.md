# Swin逐类融合补充验证（Swin测试前记录）

Swin验证集上的类间强弱不一致，因此补充按类概率融合的验证检查。只用固定模型的验证预测：每个类的原融合/Swin权重从0、0.125、0.25、0.5、0.75、1中按训练折AP选择，再按正例数n/(n+k)向全局权重收缩。k候选为global-only、10、30、100；按原视频分组5折，汇总折外mAP与Macro-F1，要求相对global-only两者都不降低，再按二者均值选择。折外检查以已固定的模型与全局TTA选择为条件，不是对整个模型选择过程的完全嵌套验证。

在全验证集重新拟合后，还要求完整验证mAP和Macro-F1不低于已选全局融合。未满足时回退到全局融合。把权重向量、阈值、候选和选择代码指纹冻结后才评估Swin测试分数。

这是真实可部署的逐类概率平均，不使用测试标签、不修改标注，也不对模型分数按测试真值归一化。每类最终分数是两个固定模型概率的凸组合。
